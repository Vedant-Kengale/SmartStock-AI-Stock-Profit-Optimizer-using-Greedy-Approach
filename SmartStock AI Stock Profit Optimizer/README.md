# SmartStock - AI Stock Profit Optimizer

## Quick Start

1. Create venv: python -m venv venv
2. Activate venv
3. Install: pip install -r requirements.txt
4. Run: python app.py
5. Open: http://127.0.0.1:5000 in browser

## Project Structure

* app.py
* templates/index.html
* static/css/style.css
* static/js/main.js
* requirements.txt

## Notes

* Greedy algorithm calculates max profit by summing profitable segments.
* LinearRegression provides simple next-day estimate.
* This demo is for educational purposes only.
